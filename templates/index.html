# OpsAgentAI A local-first autonomous AI agent that plans, uses tools, and answers with real operational context. ## Run against Ollama cloud 1. Create a `.env` file in the repo root. 2. Add your key: ```env OLLAMA_API_KEY=your_key_here ``` 3. Install dependencies: ```bash python -m venv .venv source .venv/bin/activate pip install -r requirements.txt ``` 4. Start the server: ```bash python app.py ``` 5. Send a request: ```bash curl -X POST http://localhost:5000/api/chat \ -H "Content-Type: application/json" \ -d '{"prompt":"Say hello from the Ollama cloud API."}' ``` This app calls Ollama at `https://ollama.com/api/chat` with the `Authorization: Bearer ` header and the model `glm-5.3-flash`. ## Run the CLI version ```bash python main.py ``` ## Notes - Do not commit secrets. - Keep the key server-side only. - The `.env` file is ignored by Git.
